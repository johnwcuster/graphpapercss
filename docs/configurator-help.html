Start with source order

The tools change arrangement, not reading order. The configurator’s controls are separate from Graph Paper’s CSS.

Terms used here

Workbench
The floating interface: Preview controls and the Composition panel. It does not include the rendered example.
Preview
The rendered example. Preview width sets its width here; it does not change your browser window or add a width utility to the copied classes.
Canvas
A gp_canvas element establishes the 64-bit ruler and responsive context. The preview contains one; in your own page, its width can follow its parent container. Layout transitions depend on this element’s width, not necessarily the viewport.
Field
A gp_field element selects a usable span of the canvas ruler. The Gutters options choose its outer insets, internal gaps, and, for ruled fields, space for column rules.
Recipe and macro regions
A grid_* recipe defines the composition’s broad regions and proportions. Macro regions are not independent CSS columns or a count of source items.
Positions and items
Positions are places within a recipe; a set_* class defines their number and arrangement. Items are the actual content elements in source order. Flow changes which positions those items occupy, without changing source order. An unfilled position and an extra item are different things.
Responsive states
Stacked, compact, and expanded describe layouts, not device types. A transition is the canvas width where the layout switches states. Opening an options group does not change the responsive state.
Band
A gp_band--0* class requests a minimum width for the narrowest defined item position, also called a slot. A position can span more than one macro region. Graph Paper calculates the layout transitions from that minimum. Bands use the optional, experimental bands.css stylesheet.

How controls interact

Use the Composition panel to choose the arrangement. Use Preview controls to inspect it at different widths or with visual aids. Changing the arrangement does not automatically resize the preview.

Macro-region count, letter, and variant choices select a recipe. Compatible set and flow choices stay selected. When a combination is unavailable, changing the recipe may select compatible defaults. Applied classes in the Composition panel always show the result.

Source shows one to eight items as a colored stack. Use − to remove the last item and + to append one in source order. Stack colors match the numbered preview badges and Flow illustrations. Numbers identify items without relying on color.

Changing the number of positions may change the available flows. Adding or removing source items does not change the selected set or flow. With a named set, items beyond its position count use full-width fallback placement; unfilled positions retain the selected recipe’s geometry. Without a set class, items continue sequentially into later rows. Review these cases in the preview.

Default applies only to its own choice group. For letters and variants, it selects the unlettered or unnumbered recipe. For positions, it omits the set class and places items sequentially. For flow, it omits the flow class and uses the set’s default placement. For bands, it omits the band class and uses the 30rem and 60rem canvas transitions. It does not reset the entire configuration.

Gray, borderless options remain selectable: with the current items and settings, their layouts and transition widths match across responsive states. Differences that appear only at another width still count as different layouts. White disabled options represent class combinations that do not exist. Checks and outlined options mark the current selections.

Show options reveals alternatives within its bordered group. Hide options leaves the selected illustrations visible. Neither action changes the composition. Unavailable letter options explain which setting to change to make them available.

Letter illustrations pair compact and expanded layouts. Variants illustrate expanded layouts; Flow illustrations show the current responsive state. Numbers indicate source order, not content height. Letters are recipe alternatives, not a universal left/right switch.

Arrows above variant regions compare their expanded widths with the same letter’s unnumbered Default: outward means wider, inward means narrower, and a dash means unchanged. Tooltips and accessible descriptions give bit differences. These comparisons apply even when regions are unoccupied or the preview is compact or stacked. No comparison is shown when that unnumbered recipe does not exist.

Gutters and bands can change transition widths. Test transitions sets the preview width just below or above a transition. Later settings changes update those target widths without resizing the preview again.

Workbench controls

Close panel hides only the Composition panel. Edit composition appears at its docked location to reopen it. Hide workbench or ⌥ ⇧ G (Option+Shift+G, or Alt+Shift+G) hides both the panel and Preview controls. Show workbench or the shortcut restores them. Show workbench appears at the Hide workbench button’s docked location.

Panel-outline icons identify controls that show or hide panels. Chevrons identify options groups and menus: upward means open; downward means closed.

Preview dock places Preview controls at the top, bottom, left, or right. Composition dock independently places the Composition panel on the left or right. At narrow widths, side-docked Preview controls adapt to the top, and the panel uses the available width. Docking does not change the preview width.

Visual aids add independent annotations to the preview. Help opens this page in a new tab so your configuration stays in place.

The separate 64-bit ruler checkbox beneath the site name draws guides through the documentation’s full height. It follows the documentation canvas, not the independently sized preview, and remembers your choice between pages.

Keyboard and accessibility

Tab moves between controls and choice groups. Within a choice group, arrow keys select the next or previous available option; Home and End select the first and last visible options. Unavailable options are skipped. Use Show options to include alternatives in this navigation. The selected option is the group’s single Tab stop.

Escape lets native form controls handle their own interaction; from other controls it closes an open preview menu or the Composition panel. Clicking outside a preview menu also closes it. Opening the Composition panel moves focus to its heading; closing it returns focus to Edit composition. The workbench shortcut does not run while you are editing a form field.

The tools do not trap keyboard focus. If the Composition panel covers a page control receiving focus, the panel closes without moving focus away from that control. Preview controls similarly hide if they cover page focus. Reopen buttons move clear of focused page controls when needed.

Option labels are short; accessible descriptions explain the layout and compatibility details. Source counts are announced only when changed. Position/flow changes, responsive-state changes, and copy results have separate announcements.

Migration reference

Upgrading an existing site? Start with the migration guide, which links the 0.2.3 reference and intentional geometry changes. For the CSS contract rather than these controls, use the class reference and authoring guide.

Compare the 0.2.3 three-region example with the matching current configuration.

The legacy reference accepts grid, set, flow, rhythm (neat, thin, or wide), and width URL parameters. An empty flow value omits the flow class. Its preview width is limited to 280–1200px.

Full and ruled fields have no exact 0.2.3 equivalent. Recipes added since 0.2.3, grid-only placement, and bands also lack legacy counterparts. Where available, the configurator’s resolved geometry includes the 0.2.3 comparison.
