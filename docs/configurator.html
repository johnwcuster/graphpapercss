Responsive design
What triggers layout shifts?

By default, Graph Paper switches between stacked, compact, and expanded layouts at canvas widths of 30rem and 60rem—not viewport widths.

Bands work like breakpoints, but specify a minimum useful width for the narrowest defined position. Graph Paper uses that minimum to calculate replacement transition widths as the canvas grows or shrinks. It does not measure the text inside your items.

Smaller bands allow narrower positions before switching; larger bands switch at wider canvas widths. Changing a band changes the transition points, not the canvas width.

How to read this composition

Use the Composition panel to change the arrangement and Preview controls to inspect it at different widths. Letter illustrations pair compact and expanded layouts; variants show expanded layouts, and Flow illustrations show the current responsive state. These illustrations show item relationships, not independent CSS columns.

Descriptions use design-weight proportions. Actual field-specific whole-bit boundaries are shown in the ruler and resolved geometry below. Explore recipes using the macro-region, letter, and variant controls.

Visual aids toggle independently. Band brackets show the requested structural minimum, including in stacked layouts that cannot supply it. Item boxes use actual browser measurements; they turn red when horizontal geometry differs from the recipe.
