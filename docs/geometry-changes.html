Accepted whole-bit changes

Twelve intentional adjustments place structural edges on whole-bit coordinates in the 1.0 architecture, already available in the released 0.4.0 preview. Each example compares 0.2.3 with the current CSS, unchanged from 0.4.0, at a 1024px canvas width. Edges shift by half a bit and formerly equal columns differ by one bit.

The coordinate record lists all twelve accepted replacements.
