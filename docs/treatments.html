Rules and micro-alignment

Make the exception explicit.

Rules are a visual treatment, not a fourth spacing rhythm. A small set of deliberate escape hatches handles the editorial exceptions that grid, set, and flow should not have to encode.

Rule treatment

The legacy stylesheet inferred borders through a large grid/set/flow selector matrix. The 1.0 model gives items explicit start and end rules. Each one-pixel marker is offset by half of the active gap, placing it at the gutter’s center without changing item geometry.

What Phase 8 adds—and stops at

gp_treatment--rule
Positions rule markers halfway across the active grid gap.
gp_rule--start / gp_rule--end
Add non-geometric rule markers on the named logical edge.
gp_inset--bit
Add one bit of inline content inset.
gp_place
Consumes explicit column and row start/end custom properties.
gp_optical
Consumes optical x/y translation custom properties.
There are deliberately no cell variants, bleed matrix, alignment matrix, or per-line placement classes yet. Additions need a real editorial example rather than symmetry with another utility.
