Migrating from 0.2.3 to 1.0

This guide targets the development build for the upcoming 1.0 release; 0.3.0 is the published preview. Existing sites can keep the pinned 0.2.3 release. Modern core requires updated markup and browsers with container queries, container units, and subgrid.

Add a canvas and field

Keep the grid, set, and compatible flow IDs. Add a canvas wrapper and a field:

<div class="gp_canvas">
  <section class="gp_field gp_field--wide grid_03a--01 set_06 flow_04">
    …
  </section>
</div>

A field is a direct canvas child and uses exactly one modifier: full (64 bits), neat (60), thin (59), wide (58), or ruled (56). The 0.2.3 thin/neat modifiers become field modifiers. Gutters occupy ruler bits; do not add a horizontal CSS gap to the canvas or field.

The canvas supplies the coordinate system and responsive context. Subgrid continues a semantic wrapper's inherited tracks using local line indices. A nested canvas explicitly starts a new ruler and selects its own field. A full-bleed background and inset content can share one canvas row.

Responsive layouts and reading order

Layouts respond to canvas width instead of viewport width. Defaults are expanded at 60rem, compact at 30rem, and source-order stacking below 30rem. Optional experimental bands change transition thresholds, not compact arrangements. Normalized flows and their known aliases remain. Keep logical DOM order; visual hierarchy does not change focus order.

Twelve intentional geometry changes

All 72 released recipes are represented. Of 216 neat/thin/wide comparisons, 204 match exactly. The twelve changes affect grid_03a, grid_03b, grid_03c, and grid_03d in each field: edges shift by at most half a bit and two formerly equal small columns differ by one bit. The concise coordinate record specifies the accepted replacements. Full and ruled are new field policies.

Rules and host-controlled spacing

Use gp_field--ruled and explicitly assign gp_rule--start or gp_rule--end to one owner per internal gutter. The ruled field reserves two bits per gutter and centers rules on whole-bit lines. Markers suppress themselves at field boundaries, on responsive full-span items, and in stacked mode. Rule color and width remain host-overridable.

Replace 0.2.3's combined rule modifier with this explicit ruled-field model. Core provides no global typography, image helpers, print theme, row gaps, or stacked margins. Add vertical spacing in your project:

.editorial .gp_field { row-gap: 1.5rem; }
@container gp-canvas (width < 30rem) {
  .editorial .gp_field > * + * { margin-block-start: 1.5rem; }
}

This spacing example follows the default stacked threshold. If you opt into bands or customize thresholds, adapt host spacing to those transitions as well.

Compatibility and cascade layers

compat.css is an alternative 0.2.3 profile, including its globals and viewport behavior. It is not a modern-field polyfill; do not load it alongside modern core in the same document. css/legacy/main.css retains the released baseline.

main.layer.min.css provides modern core inside the graph-paper cascade layer. Declare its order relative to your project's layers. Ordinary unlayered host styles override normal layered declarations.
