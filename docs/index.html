Graph Paper CSS

A framework-agnostic 64-bit ruler for editorial composition. No runtime JavaScript is required.

This documentation describes the development build for the upcoming 1.0 release, including unreleased authoring defaults and experimental response bands. The published preview is 0.3.0. Pin an exact release for production.

Start with a canvas and field

<link rel="stylesheet" href="css/main.min.css">
<div class="gp_canvas">
  <section class="gp_field gp_field--wide grid_03 set_03">
    <article>First item</article>
    <article>Second item</article>
    <article>Third item</article>
  </section>
</div>

The canvas establishes coordinates and available-width context. The field selects a usable span. Grid, set, and flow arrange the content; subgrid continues alignment through wrappers. Typography, component styling, and vertical spacing belong to your project.

Inspect the API

  • Configurator: choose recipes, fields, flows, item counts, and response bands; inspect real generated CSS and copy markup.
  • Architecture: field geometry, source order, subgrid, nested canvases, and rules.
  • Experimental bands: minimum-slot requirements and their limitations.
  • Migration from 0.2.3 and twelve accepted whole-bit changes.
  • Browser support and validation commands.

Choose a build

Use css/main.min.css for modern core, or css/main.layer.min.css for core in the graph-paper cascade layer. Load optional css/bands.min.css after core when using band classes; layered projects must load bands in that same layer.

The separate css/compat.css profile preserves 0.2.3 behavior; it is not a fallback to load alongside modern core. The released baseline is retained at css/legacy/main.css. See migration guidance before upgrading an existing site.
