Graph Paper CSS · Documentation

Composition, not a component theme.

A framework-agnostic CSS library for responsive editorial layouts. Choose relationships and proportions from a constrained recipe catalogue; keep your own typography, components, and content treatments.

No runtime JavaScript is required. Graph Paper supplies horizontal geometry and placement, not a design system for every part of your site.

One model, several decisions

A gp_canvas starts a 64-bit ruler and responsive context. A field selects a usable span and gutters. Grid, set, and flow arrange its direct children. Subgrid continues inherited alignment; a nested canvas starts independent coordinates.

Recipes include responsive arrangements, not just fixed column counts. Your project owns typography, image treatment, vertical spacing, and the editorial judgment that makes the composition useful. Read the architecture for the conceptual model or use the implementation checklist for a compact human/agent handoff.
